# Critique Loop

After each artifact (a primitive, a screen, an iris), run this. The goal is honest, kind, specific feedback that makes the _next_ draw better — modeling the family "30 voices" critique culture, but on demand.

## The 6 questions (run every time)

1. **Works?** — does it do its job, usable, accessible, legible?
2. **Mine?** — does it look authored by hand, or like an applied effect?
3. **Trend-chasing?** (Non-Negotiable #1) — am I copying a Dribbble/template move? Cut it.
4. **Shallow?** (Non-Negotiable #3) — does the visual connect to a real concept, or is it surface decoration?
5. **Eye-test** (Non-Negotiable #4) — does it carry the motif (ConceptEye/HandMark) or justify its absence?
6. **Redraw?** — one concrete thing to change in the next version.

## How to run it

- Self-critique first (you, honestly). Then ask the AI to critique against the same 6 + the specs.
- Disagreement is signal — log where your taste and the rules pull apart.

## Template (copy)

```
### <date> — <artifact>
1. Works:
2. Mine:
3. Trend-chasing:
4. Shallow:
5. Eye-test:
6. Redraw next:
Verdict: ship | redraw | park
```
