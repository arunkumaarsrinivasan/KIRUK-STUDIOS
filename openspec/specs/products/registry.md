# Kiruk Products Registry

> Source of truth for all in-house kiruk products. Governed by `openspec/specs/products/spec.md`.
> Entries are added/edited only through OpenSpec change proposals.

## Schema

Each entry:

```
### <slug>
- name: <display name>
- tier: tool | micro-app | extension | saas | toy
- status: incubating | live | paused | archived
- deploy-target: <url or "tbd">
- audience: <one line>
- success-metric: <one measurable thing>
- origin: greenfield | ism-graduation:<ism-slug>
- one-liner: <under 20 words, what + why>
```
