> Workbook = **spark**. This folder = **how we think and file**.
> Not the finished brand. Not look/feel. Not sustainability of the brand.
> Not OpenSpec. Not `VISION-MISSION.md` until locked.
>
> Founder = **orchestrator**. Dumps = **document-creation**. Markdown on purpose.
> Scribble origin: printed _17 Day Brand_ workbook, filled by hand.

Start here: **[overview.md](./overview.md)**

## How to use

1. Arun talks (overview, workbook page, project spark).
2. Agent follows [method.md](./method.md), [docs-map.md](./docs-map.md), and skill `brand-thinking-capture`.
3. Content lands in the **topic file** it belongs to.
4. Seeds → [ideas.md](./ideas.md). Moves → [task.md](./task.md).
5. Repo fights → [tensions.md](./tensions.md).
6. No manifesto/spec rewrite until Arun says **lock**.
