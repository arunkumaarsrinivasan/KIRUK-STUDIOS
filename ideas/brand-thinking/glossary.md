# Glossary — this thinking layer

Studio vocabulary in `CLAUDE.md` still wins in shipped work. These extra words are for **this pass**.

| Term                         | Meaning here                                                                                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Brand thinking**           | Why a move exists (association, edge, bones). Not the logo.                                                                                                                                  |
| **Spine**                    | Ordered operations from the 17-day workbook, rewritten as kiruk jobs.                                                                                                                        |
| **Dump**                     | Spoken or handwritten fill, filed into a chapter file.                                                                                                                                       |
| **Seed**                     | An idea in `ideas.md` that is not locked.                                                                                                                                                    |
| **Lock**                     | Promote into OpenSpec / `VISION-MISSION.md` after Arun says so.                                                                                                                              |
| **Kiruk Framework**          | Seed: a trigger that unleashes the _other person’s_ idea — childlike unlock, variety of frames, storytelling, bring to life. Form unset. Needs foundation before a serious client boards it. |
| **Express, don’t coat**      | Edge (07): show how the brand should be. Not a veneer that only looks different.                                                                                                             |
| **Sanxia**                   | People (06) persona: 29, illustrator, she. Thinking face for “the one.” Not a live client; no universe folder.                                                                               |
| **Cultural lock**            | What the street should associate without a pitch: pen, paper, scribble.                                                                                                                      |
| **Intersection**             | Product studio × creative development (Nothing × Immersive Garden as poles).                                                                                                                 |
| **Warm hug + rebellion**     | Soft toward the person; hard toward trends and the ordinary.                                                                                                                                 |
| **Block by block**           | Foundation, possible end-state, next step, recover when it breaks. Opposite of start-rebuild.                                                                                                |
| **Bring out the best first** | Unlock the client’s kirukal before executing a brief.                                                                                                                                        |
| **Orchestrator**             | Arun. Directs what to file. Agent does not freelance a vision rewrite.                                                                                                                       |
| **Spark**                    | The workbook (and dumps): _how_ we will create, not the finished brand.                                                                                                                      |
| **One-to-one**               | One designer, one client (or kiruk/community as client on lab work).                                                                                                                         |
| **Theme**                    | A lens (criticism, nepotism, absurdism, naturalism, heroism) picked at project definition.                                                                                                   |
| **Write-back**               | After delivery, outcomes return to the workbook / this KB.                                                                                                                                   |
| **-ism family**              | Metaphorical names orbiting _kiruk_ (kirukism, heroism, nomadism, kirukal, plus seeds). Not all are spawned ISMs.                                                                            |
| **Invitism**                 | Spoken name-seed. Not on the ISM registry. Do not spawn.                                                                                                                                     |
| **Polymnism**                | Polymath + ism. For polymaths. Seed only; not on the ISM registry.                                                                                                                           |
| **Doctor-trust**             | How money should feel: the client approaches like they would a doctor — they do not judge the craft; they hear, converse, and trust the process. Not “never ask questions.”                  |
| **GTM**                      | Go-to-market. One of the small first-month work types (Money 03). Not GPM.                                                                                                                   |

Day-1 workbook language (paraphrased, for shared use):

| Word                    | Working sense                                            |
| ----------------------- | -------------------------------------------------------- |
| **Daily job (mission)** | What you actually do, day to day, toward the end goal.   |
| **End goal (vision)**   | The picture you are working toward.                      |
| **Brand visuals**       | Expression (type, colour, layout) — comes _after_ bones. |
| **Client**              | Ongoing partnership. Not the same as a one-off customer. |
| **Marketing**           | The whole demand + trust system, not only ads.           |
