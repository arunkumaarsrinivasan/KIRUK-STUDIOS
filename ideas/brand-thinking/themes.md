# Themes — lenses for experiments

Filed 2026-09-02. These inform **direction and tone** of a project. They are not a visual system.

A project picks **one primary lens** at definition (workflow step 2). Mixing is allowed later; starting with five at once is how things spin.

## Current set

| Theme          | Working sense (seed — not locked)                             | Notes                                                                                                            |
| -------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Criticism**  | Work that looks at a thing and will not flatter it.           | New vs current ISM registry.                                                                                     |
| **Nepotism**   | Work about who gets in, who is chosen, unfair closeness.      | Handle as _inquiry_, not as a hiring policy.                                                                     |
| **Absurdism**  | Work that lets the ridiculous be true.                        | Fits kirukal / madness.                                                                                          |
| **Naturalism** | Work that stays close to what is observed, unstyled, un-hype. | Tension with “revolutionary” — can be both: honest material, extreme idea.                                       |
| **Heroism**    | Everyday courage, choice, becoming.                           | Already a **reserved ISM name** in `openspec/specs/ism/spec.md`. Do not spawn the folder until `/kiruk-ism-new`. |

Older ISM names still on the registry (heroism, kirukism-series, colorism, nomadism) are **not deleted**. This list is the experimental tone set for _this_ pass. Overlap to resolve later: heroism is on both lists; kirukism/colorism/nomadism are not on this five.

## Rule

Do not create `kiruk-ism/<theme>/` from this file. Theme in the KB ≠ spawned ISM.
